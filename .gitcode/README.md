# GitCode 协作模板

本目录存放 GitCode 平台的协作模板，用于规范 Issue 与 Pull Request 的提交内容。

## 目录结构

```text
.gitcode/
├── README.md                          # 本说明
├── PULL_REQUEST_TEMPLATE.zh-CN.md     # Pull Request 模板
└── ISSUE_TEMPLATE/
    ├── bug-report.yml                 # 缺陷反馈
    ├── feature-request.yml            # 功能建议
    ├── documentation.yml              # 文档问题
    ├── question.yml                   # 使用咨询
    └── request-for-comments.yml       # 方案意见征集
```

## 使用方式

- 提交 Issue 时，在 GitCode 页面选择对应模板并填写完整信息。
- 提交 Pull Request 时，按照 `PULL_REQUEST_TEMPLATE.zh-CN.md` 的结构描述背景、方案与验证结果。
- 更多协作流程与代码规范见 [贡献指南](../CONTRIBUTING.md)。
